# ATLAS persistent memory

Keep durable memory concise, useful, and distinguishable from temporary conversation context. Prefer stable preferences, recurring project decisions, and unfinished work that would otherwise be hard to recover.

For ongoing technical projects, record:
- the goal and relevant constraints;
- confirmed decisions and decisions still owned by the user;
- changes actually made and their evidence;
- current blockers and the next concrete step.

Do not record secrets, API keys, passwords, tokens, or unnecessary private financial/account details. Date time-sensitive facts. Do not claim to have saved a memory unless the write succeeded.

Use OpenClaw's native session and memory facilities. This file is a workspace note, not a replacement runtime or a claim that semantic memory is already configured.
