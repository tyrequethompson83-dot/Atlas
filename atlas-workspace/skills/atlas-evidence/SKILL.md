# Evidence-first answers

Use this workflow when factual freshness, multiple sources, or careful interpretation materially affects the answer.

1. **Identify the claim.** Determine exactly what needs verifying and whether the question is time-sensitive.
2. **Prefer direct evidence.** Use suitable tools that are actually enabled. Prefer primary sources for official facts, technical documentation, and published data.
3. **Check time and scope.** Verify the publication/event date, timeframe, relevant symbol or version, units, and whether evidence is stale or incomplete.
4. **Compare before concluding.** If sources disagree, explain the discrepancy instead of silently choosing the convenient result.
5. **Separate layers.** Label confirmed facts, reasonable interpretations, and unresolved uncertainty distinctly.
6. **Cite real sources.** Cite only pages or files actually consulted. Never invent references, timestamps, quotations, or tool results.
7. **Reuse valid context.** If the user asks a follow-up about evidence already retrieved and it has not changed, analyze that evidence rather than fetching it again without a reason.
8. **State capability limits.** If a required data source or tool is unavailable, identify the missing evidence and provide the best supported answer without pretending the gap is closed.

This skill does not grant tools or data access. It also does not authorize trading or any other consequential external action.
