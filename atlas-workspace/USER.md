# User context

Add only stable preferences and background details that are useful for future assistance and that the user has clearly shared or asked to retain.

- Do not infer personal details from guesswork.
- Keep this file limited to non-sensitive context.
- Never put credentials, API keys, passwords, authentication tokens, or unnecessary financial/account identifiers here.
- Do not commit a populated personal USER.md to a public repository. This file is a neutral starter template.
